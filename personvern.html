Personvernerklæring for Hjem

Hjem er et privat hjemmesystem som bare brukes av én husstand.

Hvilke data brukes

Med husstandens eget samtykke leser og skriver Hjem hendelser i husstandens felles Google-kalender. Senere kan systemet også lese og sende e-post fra husstandens felles Google-konto.

Hvor dataene lagres

Data fra Google lagres bare midlertidig på husstandens egen server i hjemmet. Dataene vises på husstandens egne enheter.

Deling

Data fra Google deles ikke med, selges ikke til og overføres ikke til andre. Bruken av data fra Google API-er følger Google API Services User Data Policy, inkludert kravene om begrenset bruk (Limited Use).

Tilbaketrekking

Tilgangen kan når som helst trekkes tilbake på myaccount.google.com/permissions.

Kontakt

Via GitHub: github.com/eakleven

Privacy policy (English)

Hjem is a private home dashboard used by a single household. With the household's consent it reads and writes events in the household's shared Google Calendar, and may later read and send email from the household's shared Google account. Data is stored only temporarily on the household's own server at home and shown on the household's own devices. Data from Google is not shared with, sold to or transferred to anyone. Use of data from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked at any time at myaccount.google.com/permissions.
